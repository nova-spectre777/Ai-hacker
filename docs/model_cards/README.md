# Model Cards

Create a model card for each trained artifact. Do not reuse a generic model card as evidence that training succeeded.

Each card should include model revision and configuration, initialization type, tokenizer, training data provenance and license, training hardware and settings, evaluation metrics, intended use, limitations, known risks, artifact hashes, and the exact date/version of the run.

The [base-code language-model card](base-code-language-model.md) describes the current training recipe only; it contains no claimed training results.
